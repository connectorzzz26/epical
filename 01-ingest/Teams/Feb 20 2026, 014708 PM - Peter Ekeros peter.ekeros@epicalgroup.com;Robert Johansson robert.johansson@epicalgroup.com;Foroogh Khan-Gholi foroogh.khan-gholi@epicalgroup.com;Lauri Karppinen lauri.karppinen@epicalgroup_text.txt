FYI 


We had a discussion sometime back in team Falcon's retrospective about making bicep modules updates more transparent.


So, a task was created to create a new channel, and post updates about the bicep module changes there.


 


The channel is called: NCIP Bicep Module Updates


And it is under the NCIP Integration Dev Team in NCC domain.


 


A 
template has been added to the Common-BicepModules-Containers repo, which will show up when a new PR is created there.


Once the template is filled in the PR description, and the PR is completed, a new card will be sent to the channel with the information about the update. The card looks like this:
