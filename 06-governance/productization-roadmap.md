# Productization Roadmap

| Phase | Name | Outcome |
| --- | --- | --- |
| POC | Thaer baseline case | End-to-end case narrative and control-plane model proven. |
| v0.1 | Governed single-case run | Case manifest, roles, source coverage, and disclosure log used together. |
| v0.2 | Reusable case templates | New employee DSAR can start from manifest/role/evidence templates. |
| v0.3 | Signed agent roles | Agent enrollment and revocation become executable. |
| v0.4 | Connectome visualization | Authority, agents, services, feedback, and revocations visible. |
| v0.5 | Backer treaty sandbox | Metadata-only support services validated safely. |
| v1.0 | Employee GDPR compliance mesh | Repeatable governed DSAR product for employee enterprise data. |

## What not to build first

- generic chatbot interface
- broad external processing of raw employee data
- autonomous legal conclusions
- public demos with real private material
- complex marketplace of backer services before treaty boundaries are proven
