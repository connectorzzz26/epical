# Metrics

| Metric | Why it matters | Target after successful POC |
| --- | --- | --- |
| Source coverage completeness | Proves search scope. | 100% expected sources classified as covered or gap-stated. |
| Evidence-to-finding traceability | Prevents unsupported claims. | Every finding has source reference or gap label. |
| Third-party redaction count | Shows minimisation work. | Count recorded per deliverable. |
| Unresolved gaps | Keeps omissions visible. | All gaps listed with owner/action. |
| Processing time | Product value. | Baseline measured from intake to draft response. |
| Revoked/expired trust edges | Proves revocation is active. | At least closure/event examples recorded. |
| Claims without direct evidence | Detects influence/hallucination risk. | Zero in final deliverables. |
| Reviewer comments separated from evidence | Controls feedback loops. | 100% reviewer inputs classified by lane. |
| Backer raw-data exposure | Privacy guardrail. | Zero by default. |
| Employee challenge points preserved | Fairness/accountability. | 100% tracked to resolution or unresolved status. |
