# Compliance Mesh Demo Script

## 5-minute flow

1. Open `README.md`.
   - Say: this is a governed employee GDPR compliance mesh, not just a DSAR folder.

2. Show the pipeline.
   - `01-ingest -> 02-index -> 03-analysis -> 04-redacted-evidence -> 05-deliverables`.

3. Open `GENESIS_MESH_EMPLOYEE_GDPR_CONTROL_PLANE.md`.
   - Explain `MiraOS-NA` as anchor and `EPICAL-NA` / `epical-na` as Network Authority.

4. Open `06-governance/case-manifest.example.yaml`.
   - Show purpose, evidence boundaries, forbidden processing, and success criteria.

5. Open `06-governance/agent-roles.yaml`.
   - Show signed, scoped, revocable roles.

6. Open `06-governance/influence-map.md`.
   - Explain how evidence is separated from reviewer feedback and hidden influence loops.

7. Open `06-governance/source-coverage-matrix.md`.
   - Show how omissions become explicit instead of hidden.

8. Open `06-governance/regulator-pack-index.md`.
   - Show how the governed run becomes explainable to counsel or a regulator.

## Closing line

Epical can prove not only what it disclosed, but how the disclosure was governed.
