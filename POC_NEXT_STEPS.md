# POC Next Steps

## Assumption

The initial Genesis Mesh employee GDPR POC has succeeded as a controlled baseline: the repo now shows the pipeline, the control-plane thesis, the `MiraOS-NA` / `EPICAL-NA` authority model, and the evidence-vs-influence framing.

## What now exists

- Root narrative: governed employee GDPR compliance mesh.
- Genesis Mesh detail folder: `06-genesismesh/`.
- Governance operating-model folder: `06-governance/`.
- Case manifest, agent roles, evidence classes, treaty template, source coverage matrix, influence map, processing register, redaction policy, disclosure log, connectome example, regulator pack index, metrics, and roadmap.

## What needs to become real next

1. Replace example manifest values with signed case data.
2. Generate a real source coverage matrix from the current inventory.
3. Attach every finding to source references or gap labels.
4. Convert agent-role YAML into executable checks.
5. Emit Connectome events during pipeline execution.
6. Implement revocation checks before any service call.
7. Produce a demo using only redacted or synthetic material.
8. Decide which artifacts are internal, counsel-facing, regulator-facing, or public.

## What remains demo-only

- `connectome-example.json` until generated from runtime events.
- treaty templates until signed by real authorities.
- backer service use until explicit approval and data boundaries exist.
- Nordcloud-style influence framing unless tied to specific evidence.

## What must stay private

- raw HR/payroll/identity/health material
- unredacted Teams/SharePoint exports
- third-party personal data
- customer/supplier confidential data
- legal strategy drafts unless approved

## Product-market proof

The next proof is not more text. It is a governed case run where the repo can show:

- what was searched;
- what was missing;
- who processed each evidence class;
- which feedback was accepted, disputed, or rejected;
- which services were trusted or revoked;
- what was disclosed and why.

That is the moment this becomes an operating model, not only a POC.
